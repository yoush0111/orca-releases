# orca-releases

[Orca](https://github.com/stablyai/orca) 포크의 내부 배포용 설치본 저장소입니다.
**바이너리만** 올라오며, 소스는 공개하지 않습니다.

최신 설치본: **[Releases 최신 버전](https://github.com/yoush0111/orca-releases/releases/latest)**

---

## 설치

### Windows

1. 최신 릴리즈에서 `orca-windows-setup.exe`를 받아 실행합니다.
2. 미서명 빌드라 SmartScreen 경고가 뜹니다 → **추가 정보 → 실행**.
3. 이후 버전은 **자동 업데이트**됩니다. 다시 받을 필요 없습니다.

> **`1.0.6-personal` 이전 버전을 쓰고 있다면 한 번만 수동으로 재설치해야 합니다.**
> 그 이전 빌드는 업데이트 피드가 upstream(`stablyai/orca`)을 가리켜서 이 저장소의 릴리즈를 보지 못합니다.
> 한 번 재설치하면 그다음부터는 자동 업데이트가 정상 동작합니다.

### macOS

**현재 배포하지 않습니다.** 지금까지의 릴리즈는 모두 Windows 설치본뿐입니다.

electron-builder는 macOS 타깃을 크로스 빌드할 수 없어 별도의 Mac 빌드 머신이 필요합니다.
필요해지면 같은 태그에 `.dmg`를 함께 올릴 예정입니다.

## upstream과 다른 점

업스트림 Orca에 **Redmine 연동**을 얹은 빌드입니다. 그 외 동작은 upstream과 같습니다.

### Redmine을 작업 소스로 사용

GitHub · GitLab · Jira · Linear에 이어 **Redmine이 다섯 번째 작업 소스**로 추가됩니다.
`Settings → Redmine`에서 Redmine 주소와 REST API 키로 연결하면, Tasks 탭에서 일감을 조회할 수 있습니다.

- API 키는 Redmine의 **내 계정 → API 액세스 키**에서 확인합니다.
  (Redmine 관리 설정에서 REST API가 활성화돼 있어야 합니다.)
- 목록에서 내 담당 / 프로젝트 / 상태로 필터링할 수 있습니다.
- 일감 행에서 바로 워크스페이스를 만들 수 있고, 브랜치명은 `feature/<일감번호>-<제목-슬러그>`로 자동 생성됩니다.

### 프로젝트별 repo 매핑

`Settings → Redmine → Project repositories`에서 Redmine 프로젝트마다 작업할 repo를 지정해 두면,
일감의 **→** 버튼이 그 repo로 워크스페이스 컴포저를 엽니다. 서브프로젝트는 부모 설정을 물려받습니다.
지정한 repo는 일감 목록의 프로젝트 열에도 표시됩니다.

### 일감 링크를 Orca 안에서 열기

Redmine 일감 링크는 기본적으로 **플로팅 워크스페이스의 브라우저 탭**으로 열립니다.

| 동작 | 결과 |
|---|---|
| 클릭 (기본) | 플로팅 워크스페이스 브라우저 탭 |
| 설정에서 끈 뒤 클릭 | 활성 워크트리 탭 |
| `Shift` + `Ctrl` + 클릭 | 시스템 기본 브라우저 |

플로팅 워크스페이스에서는 타이틀바 토글로 **Redmine 작업 뷰**를 열 수 있고, 토글 상태는 재시작 후에도 유지됩니다.

## 패치 노트

### 1.0.11-personal — 2026-09-03

- upstream 최신 반영 (139커밋, 2026-09-02 기준). 기능 변경 없음.

### 1.0.10-personal — 2026-09-02

- upstream 최신 반영 (251커밋, 2026-09-01 기준). 기능 변경 없음.
- upstream이 Tasks 화면을 작업 소스별 트리로, 플로팅 워크스페이스 패널을 상태/화면 두 층으로 분해했습니다.
  Redmine 작업 소스와 플로팅 작업 뷰(타이틀바 토글, 재시작 후 상태 유지)를 새 구조에 맞춰 재이식했으며,
  화면과 동작은 이전과 같습니다.

### 1.0.9-personal — 2026-08-31

- upstream 최신 반영 (302커밋, 2026-08-30 기준). 기능 변경 없음.
- upstream이 기본 설정값을 별도 모듈로 분리하면서, Redmine 관련 기본값(작업 소스 노출, 링크 플로팅 열기)을 새 위치로 재이식했습니다.

### 1.0.8-personal — 2026-08-27

- upstream 최신 반영 (61커밋, 2026-08-26 기준). 기능 변경 없음.
- 릴리즈 빌드를 GitHub Actions에서 **로컬 빌드로 전환**했습니다. 배포본 동작은 이전과 같습니다.

### 1.0.7-personal — 2026-08-26

- upstream 최신 반영 (124커밋, 2026-08-25 기준). 기능 변경 없음.
- upstream이 컴포저 상태 훅을 서브훅으로 분해하면서, Redmine 브랜치명 로직을 새 구조에 맞춰 재이식했습니다.

### 1.0.6-personal — 2026-08-23

- **포크 자동 업데이트 수정.** 업데이트 확인이 항상 upstream 저장소를 보던 문제를 고쳤습니다.
  이제 설치본의 `app-update.yml`에 적힌 owner/repo를 따릅니다.
- **이 버전부터 자동 업데이트가 정상 동작합니다.** 이전 버전 사용자는 한 번 수동 재설치가 필요합니다.

### 1.0.5-personal — 2026-08-21

- 플로팅 워크스페이스용 **Redmine 작업 뷰** 추가 (타이틀바 토글, 재시작 후 상태 유지).
- Redmine **프로젝트별 repo 매핑** 추가 → 워크스페이스 컴포저의 기본 repo로 사용.
- 일감 목록 프로젝트 열에 매핑된 repo 표시.
- 작업 탭에서 Redmine 설정으로 바로 이동하는 버튼 추가.
- 작업 뷰가 새로 활성화된 탭에 자리를 비켜주도록 수정.

### 1.0.4-personal — 2026-08-21

- 일감 링크 **플로팅 열기를 기본값(on)** 으로 변경.
- 플로팅 열기가 켜져 있으면 Link Routing 설정과 무관하게 Orca 안에서 열립니다.

### 1.0.3-personal — 2026-08-21

- Redmine 일감 링크를 **플로팅 워크스페이스로 여는 설정** 추가.

### 1.0.2-personal — 2026-08-21

- 릴리즈에 `latest.yml`을 포함하도록 수정. 이게 없어 자동 업데이트가 새 버전을 찾지 못했습니다.

### 1.0.1-personal — 2026-08-21

- 자동 업데이트 피드를 이 저장소로 돌리는 빌드 오버라이드 추가.

### 1.0.0-personal — 2026-08-21

- 최초 배포. **Redmine을 작업 소스로 추가** (연결 다이얼로그, 설정 카드, 일감 목록 패널).

## 버전 표기

`1.0.N-personal`은 이 배포본의 자체 번호이며, upstream Orca의 버전과는 무관하게 증가합니다.
각 릴리즈가 어떤 소스로 빌드됐는지는 소스 저장소의 동일한 이름의 태그로 추적합니다.
